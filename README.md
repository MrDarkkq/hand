# Простая кнопка с управлением через URL

Одностраничный веб-интерфейс для демонстрации состояния кнопки, которое можно изменять двумя способами: через параметры URL или нажатием на саму кнопку.

## Внешний вид

- Центрированная карточка с крупной кнопкой
- Кнопка меняет цвет и надпись в зависимости от состояния:
  - **ВКЛ** — зелёная кнопка с текстом "ВКЛ"
  - **ВЫКЛ** — красная кнопка с текстом "ВЫКЛ"
  - **Ожидание** — нейтральная серая кнопка "🔘"
- Текстовый индикатор статуса под кнопкой
- Подсказка с ссылками для изменения URL

## Управление

### Способ 1 — через URL (основной)
Добавьте один из параметров в конец адресной строки:

| Параметр | Результат |
|----------|-----------|
| `?press_on` | Кнопка переключается в состояние ВКЛ |
| `?press_off` | Кнопка переключается в состояние ВЫКЛ |
